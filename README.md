# ASCII Aquarium Wallpaper

Легкі інтерактивні живі ASCII-шпалери акваріума для **Windows 11 (24H2 / 25H2)** та Windows 10 на чистому **C++17 + Win32 + Direct3D 11 + DirectComposition** (~300 КБ `.exe`, без Chromium/Electron і сторонніх рушіїв).

## Можливості
- **Живий ASCII-акваріум:**
  - Хвилі на поверхні води (`~`, `≈`, `^`), діагональні промені світла та бульбашки, що спливають і лопаються біля поверхні.
  - Різнокольорові зграйки маленьких і середніх рибок (`><>`, `><°>`, `><((º>`, `><(((°>`, смугасті риби-клоуни), 3-рядкові рифові рибки й скалярії, риба-фугу (надувається у колючу кульку при переляку!), морська черепаха, морські коники та пульсуючі медузи.
  - Піщане дно, автоматично підняте вище панелі завдань Windows (`SPI_GETWORKAREA`), пишні листкові водорості, каміння, корали, мушлі, краб, що повзає по дну, і затонула скриня зі скарбами, яка періодично відкривається та випускає золоті бульбашки.
- **Взаємодія прямо на робочому столі:**
  - **Рух курсору:** рибки реагують на рух мишки, риба-фугу надувається, краб піднімає клешні й тікає вбік, водорості колишуться від течії, а скриня відкривається при наведенні.
  - **Швидкий клік по порожньому місцю столу:** у воду падає ASCII-корм (`•`, `·`, `*`) із хвилею на воді — рибки самі розвертаються й пливуть його їсти.
- **Справжні шпалери Windows 11 24H2 / 25H2:** вбудовується позаду іконок робочого столу через **Direct3D 11 + DXGI SwapChain + DirectComposition**, не перекриває іконки й не заважає роботі.
- **Автопауза в іграх:** автоматично ставить рендер на паузу при запуску повноекранних ігор (CS2 тощо) або блокуванні екрана.
- **Керування з системного трею:**
  - Погодувати рибок
  - 5 колірних тем: *Глибокий океан*, *Матриця (зелений)*, *Ретро-бурштин*, *Неон / Кіберпанк*, *Монохром*
  - Увімкнути/вимкнути реакцію на мишку, автопаузу, паузу
  - Автозапуск разом із Windows в один клік

## Запуск
- **Як шпалери робочого столу:** запустіть `AsciiAquariumWallpaper.exe`
- **Режим звичайного вікна (для перегляду/тесту):**
  ```powershell
  .\AsciiAquariumWallpaper.exe --window
  ```
  Клавіші у віконному режимі: `Space` — погодувати рибок, `T` — перемкнути тему, `Esc` — вихід.

## Збірка з вихідного коду
Потрібен компілятор **MinGW-w64 (`g++`)** з підтримкою C++17:
```bat
build.bat
```
Або вручну:
```bat
g++ -std=c++17 -O2 -s -Wall -Wextra -mwindows -municode -static -static-libgcc -static-libstdc++ src/main.cpp src/aquarium.cpp -o AsciiAquariumWallpaper.exe -lgdi32 -luser32 -lshell32 -ladvapi32 -lcomctl32 -ld3d11 -ldxgi -ldcomp -lole32
```
